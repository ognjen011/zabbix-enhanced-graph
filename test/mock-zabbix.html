Enhanced graph theme - mock Zabbix page

Zabbix theme Hover a graph for values, click a legend row to hide a line, hover top-right of a graph for “Classic graph”.
Each graph below is a plain grey image standing in for the classic Zabbix PNG (chart2.php / chart.php). The module script finds those images and draws the enhanced graph on top, exactly like on a real Zabbix page. Sample data only.
